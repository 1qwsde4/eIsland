# eIsland bauen lassen (nur im Browser, nichts installieren)

1. Auf github.com anmelden (kostenloses Konto) und https://github.com/JNTMTMTM/eIsland öffnen → oben rechts "Fork" → "Create fork".
2. In DEINEM Fork: "Add file" → "Upload files". Den Inhalt dieses ZIPs entpacken und die Ordner/Dateien per Drag & Drop hochladen (die Ordnerstruktur bleibt erhalten). Unten "Commit changes".
3. Oben "Actions" → falls gefragt "I understand my workflows, enable them" → links "Build eIsland Windows (Setup + Portable)" → "Run workflow".
4. Nach ca. 20–40 Minuten ist der Lauf grün. Auf den Lauf klicken → unten bei "Artifacts" **eIsland-Windows-x64** herunterladen.
5. ZIP entpacken: darin eIsland.exe, eIsland-Setup.exe und eIsland-Portable.zip.
